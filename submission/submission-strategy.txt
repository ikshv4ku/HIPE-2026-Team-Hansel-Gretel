Please find attached our official submission for the HIPE-2026 Shared Task on Person-Place Relation Extraction. We are submitting 3
runs as Team Hansel&Gretel.

Run 1 — Fine-Tuned Generative LM (Strategy 5)
- Base Model: Qwen/Qwen2.5-3B-Instruct
- Parameters: ~3 billion
- Model Size: ~6.2 GB (bfloat16); LoRA adapter checkpoint ~48 MB
Run 2 — Multi-Agent Fine-Tuned LM (Strategy 7)
- Base Model: Qwen/Qwen2.5-7B-Instruct
- Parameters: ~7 billion
- Model Size: ~15.2 GB (bfloat16); 3 LoRA adapter checkpoints ~48 MB each (~144 MB total)
Run 3 — Zero-Training Few-Shot LLM + Wikidata Knowledge Injection (Strategy 9)
- Base Model: OpenAI GPT-OSS 120B (accessed via IBM RITS inference gateway)
- Parameters: ~120 billion
- Model Size: ~240 GB (bfloat16, cloud-hosted; no local footprint)
All prediction files are formatted according to the official HIPE-2026 JSONL schema and have been validated against the official
`check_jsonlschema.py` script provided by the organisers.
